# Tab integration direction

The user confirmed that the UI should feel like an extension of Risk of Rain 2's existing Tab menu. The previously delivered PNG is a temporary standalone layout study, not the intended final navigation or a native game capture.

## Observed original source

| Area | Current implementation | Required change |
|---|---|---|
| Entry point | Plugin.Open parents SheetView to hud.scoreboardPanel.transform | Retain the existing mapped Tab/scoreboard entry point |
| Native structure | SheetView draws a large opaque root over most of the scoreboard | Keep the native scoreboard/player/inventory structure visible; place additions in the own-character region |
| Navigation | New Character, Inventory and Effects buttons inside the custom panel | Remove this default standalone navigation; expose stats and richer hovers alongside the existing inventory |
| Inventory | Custom tall vertical item rows generated by SheetData.Inventory | Expand the presentation of the existing own inventory, with stable item hover targets and optional grouping |
| Stats | Separate Character tab | Add a compact own-character stats panel; hover shows ordered source breakdown with explicit incomplete/discrepancy labels |
| Appearance | Built-in Arial, hard-coded custom colors and manually created panels | Reuse native runtime styles/fonts/panels/icons through reviewed integration; no extracted or bundled proprietary assets |
| Search | No search field exists in SheetView; web mockup alone had one | Omit search from the default Tab view; defer any optional collapsed advanced control |
| Tooltip | Plain fixed-size popup with Shift/full text and separate row luck badge | Add the current inline item scaling, next-copy change, expanded conditions and bottom-right scoped luck hover |

This inspection read only our existing source. It did not inspect game assets or establish that any native style or hierarchy is available at runtime. Being parented to the native scoreboard alone does not make the custom panel a native extension.

## Original mock layout direction

The source-only schematic in preview/character-sheet-preview.html now shows a retained Tab scoreboard region and own player/inventory card, a compact additive stats region and a Prayer Beads hover. It has no dashboard tabs, search bar or default sorting/filter toolbar. Native geometry/styles/assets are deliberately not reproduced or claimed. All character/inventory values remain synthetic.

The existing Library PNG/version1 remains the earlier temporary dashboard concept. No new image was rendered or uploaded for this revision. The source schematic is not visually tested.

## Next implementation action

Refactor SheetView around the retained native own-player/inventory view rather than its opaque replacement-like panel. Keep Plugin's mapped scoreboard opening and cleanup lifecycle, and attach stats and richer hovers without suppressing the existing scoreboard/inventory. Reuse runtime native resources only after the existing parent/user terms and integration gate permits the necessary review/testing. Wire the independent item-tooltip model into the reviewed adapter, retaining unavailable/discrepancy labels.

Do not change the staged DLL, installed profile, bootstrap or game files, launch the game, extract assets, or claim native integration is working during the current hold. Original standalone source, documentation and synthetic data remain the authorized work.
